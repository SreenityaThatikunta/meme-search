# Images for the docs

`demo.png` — the Streamlit UI returning results for `monday morning` in hybrid mode,
captured from the demo build (`streamlit run demo/space_app.py`). It is referenced at the
top of the root [README](../../README.md).

To refresh it: run the demo, search something that fills the result grid, and screenshot
the search bar plus the first row of results. `exam stress` and `monday morning` both
demo well. Keep the sidebar in frame — the index size and model line are useful context.
